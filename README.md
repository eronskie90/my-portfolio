# My Portfolio

A personal portfolio website built with Python and Flask.

## About

This portfolio showcases my background, skills, projects, and experience as an Information Technology graduate interested in Python programming and software development.

## Built With

* Python
* Flask
* HTML
* CSS

## Project Structure

```text
My Portfolio/
├── app.py
├── requirements.txt
├── static/
│   └── style.css
├── templates/
│   └── index.html
└── .gitignore
```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/eronskie90/my-portfolio.git
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Then open the local address shown in the terminal.
